<h1 align="center">QLauncher</h1>

### Современный, стильный и быстрый кастомный лаунчер для Minecraft на базе WPF (.NET 10)




## Ключевые возможности

### Премиальный интерфейс 
- **Тёмная тема** с акцентными цветами.
- **Минималистичный TitleBar** и удобная верхняя навигационная панель (`Главная`, `Моды`, `Сборка`, `Скриншоты`, `Консоль`, `Папки ▾`).
- **Кастомные всплывающие Toast-уведомления** вместо устаревших системных диалогов Windows.

### Мощное управление сборками
- **Создание сборок Vanilla / Fabric / Forge** прямо в выпадающем списке версий (`Создать новую сборку`).
- **Управление локальными модами**: включение, отключение, удаление и открытие папки модов.
- **Управление мирами**: резервное копирование (Zip-бэкап) и безопасное удаление сохранений.
- **Импорт и экспорт сборок в Zip**: возможность делиться готовыми сборками с друзьями.
- **Создание ярлыков быстрого входа на рабочий стол**.

### Движок обхода блокировок
- **Работа БЕЗ VPN**: Автоматическое переключение на доверенное зеркало **BMCLAPI** при блокировке серверов Fabric Meta провайдером.
- **Прямая загрузка OpenJDK Java**: Постоянные зеркала Azul Zulu CDN и BMCLAPI для Java 8, Java 17 и Java 21.
- **Зеркалирование новостей Telegram**: Резервные узлы для стабильной загрузки ленты новостей.

### Мониторинг серверов и аналитика
- **Живые бейджи онлайна серверов** (`142 / 500 онлайн • 24 ms`) с индикаторами пинга.
- **Трекинг игрового времени**: статистика запущенных сборок и отработанных минут.
- **Интеграция с Discord RPC**: гибкая настройка статуса с возможностью скрытия IP-адресов.

## Сборка и запуск проекта

### Требования:
- **Windows 10 / 11**
- **.NET 8.0 SDK**

```bash
# Клонирование репозитория
git clone https://github.com/dyagyatis/QLauncher.git

# Переход в директорию
cd QLauncher

# Сборка проекта
dotnet build

# Запуск приложения
dotnet run
```

---

## Релизная сборка (Publish)

Для создания автономного готового приложения выполните:
```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```
